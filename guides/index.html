Read this before copying a code

The pizza number is fixed. The prison combination is not: every new game generates four values. The dial guide explains where each clue comes from, while the door guide explains how to use those values.

These guides use the supplied Demo V2 objectives and puzzle scripts. The locally restored browser build can differ visually from the original desktop release. Source checks and captured scenes are identified separately; they do not imply every route has been replayed end to end.
