Chapter 1 Demo · Field guide

Prison Door Code & Lock Solution

There is no fixed prison door code in Frankie's Fun House. Match your red, blue, green and pink clues, install missing dials, and troubleshoot the Demo V2 lock.

Demo V2 · Source checkedUpdated September 16, 20265–7 min read

Need the short route?

Quick answer

There is no universal prison door code. Use your own run's clues in Red → Blue → Green → Pink order: red candles, blue fortune, green balloon, pink cotton candy. Install the missing blue and pink dials before setting the lock.

New game, new values

The combination is generated when a new run begins. A screenshot or video can show where to look, but its digits are not a password for your save.

Hints before the full answer

Hint 1 · Follow colors, not discovery order＋

The room supplies four values. Their discovery order does not decide the lock order; match each value to its color.

Hint 2 · Separate parts from values＋

The cake hides the blue dial but its candles supply red. The fortune teller supplies blue and makes the pink dial available. Cotton candy supplies pink.

Set the four-color combination

Reveal the complete lock procedure＋

  1. Complete the mechanism

    Collect the blue dial from the cake and the pink dial from the bed after the fortune teller. Select each in the backpack and attach it to its matching empty position.

  2. Match the four clues

    Red: red candles on the cake. Blue: fortune teller's lucky number. Green: number revealed by the popped balloon. Pink: number formed by the cotton candy.

  3. Set the lock in its color order

    Work through red, blue, green, then pink. Turn each control until it displays the value recorded for that color. Use the actual clue, not a mirrored reading or another player's digits.

  4. Open the cell

    Once the mechanism is complete and all values match, finish the lock interaction and open the door. Wait for the objective to update before moving on.

The code looks correct, but the door stays shut

Check both missing parts

Having a dial in your backpack is not enough. Both blue and pink must be attached to the mechanism.

Re-check the color mapping

Candles are red, not blue. The fortune is blue, not pink. Check the clue-to-color table before redoing puzzles.

Do not reuse a previous run's digits

Starting over generates a different combination. Notes from an earlier slot can be wrong even when the room looks identical.

Allow the interaction to finish

Exit close inspection, re-center the lock or door, and try the interaction prompt again. Confirm the game window has focus.

Check the demo version before resetting

The supplied V2 patch notes mention a correct-code issue after reloading. If playing an older build, compare versions first. Back up your save where possible; clearing browser site data can erase it and is not a first troubleshooting step.

What happens after the door opens?

Leave the cell, follow the new objective to collect the prize, then take the final exit. The next part is covered in the Chapter 1 ending walkthrough.
